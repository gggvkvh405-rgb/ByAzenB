# Клинок и Монеты: Кузница Хаоса

Мобильная idle/auto-battler RPG в портрете, управление одним пальцем.
Ты — бессмертный кузнец-охотник: монстры лезут бесконечно, ты рубишь их, собираешь золото,
выбиваешь оружие, крафтишь абсурдные билды и постепенно становишься ходячим хаосом.

> Реализовано как полностью офлайн-игра (HTML5 + Canvas) в нативной Android-оболочке (WebView).
> Никаких серверов, авторизации и интернета — всё считается и сохраняется на устройстве.

---

## Что внутри (играбельный вертикальный срез концепта)

**Бой**
- Автобой + тап-урон, комбо-тапы (+5% урона за тап, до ×3.5), крит с тряской экрана
- Ярость → ульта класса: Метеор, Вихрь клинков, Ледяная нова, Берсерк, Град стрел, Теневой удар,
  Турель, Корни, Жертва, Шторм Хаоса…
- Волны, босс каждые 10 волн (20 боссов со своими механиками: кража золота, призыв, щиты,
  отражение урона, «бан», смена правил, телепорт…)
- Мутации монстров: броня, щит, яд, лечение, взрыв, деление, скорость, вампиризм, шипы, аура страха
- Статусы: горение, яд, кровотечение, заморозка, замедление, стан, страх
- Смерть → воскрешение за «рекламу» или откат на 1 волну

**Прогрессия**
- 11 героев-классов с пассивками, отряд до 3 человек, смена прямо в бою
- 12 слотов экипировки, 8 редкостей (Обычное → … → Хаоситное), ~150 предметов из концепта
- 10 сетов (бонусы за 3 и 5 предметов), 20 рун с гнёздами, 25 питомцев, артефакты и реликвии
- Кузница: улучшение, разбор, слияние 3→1, крафт, реролл, наложение и снятие проклятий
- Дерево талантов (Война / Жадность / Хаос)
- Престиж → Ассеншен → Трансценденция → Пробуждение, 4 дерева вечных бонусов
- Врата выбора после босса (12 баффов), погода и время суток (6 типов), 11 биомов, коллекция, титулы, репутация фракций

**Мета-системы**
- Баттл-пасс «Пробуждение Кузницы» (150 уровней, free/premium/premium+ дорожки)
- Ежедневные / еженедельные / сезонные задания, 32 достижения
- Магазин, торговец со случайным ассортиментом, Кузнечный портал (гача с pity 50), сундуки
- Арена (асинхронный PvP, лиги и рейтинг), магазин арены
- Оффлайн-доход (до 2 часов, прокачивается до 8) + сундук с ×2
- Мини-игры «как из рекламы», но реально играбельные: Врата, Спаси принцессу, Убей слизь, Выбери сундук
- Добровольная «реклама»: ×2 золото, воскрешение, сундук; промокоды (CHAOS, FORGE, 404, DONATE, PATCH, …)
- Экспорт/импорт сохранения, настройки звука, тряски, частиц, авто-разбора лута

**Техника**
- Vanilla JS + Canvas 2D, без сборщика и без внешних зависимостей (работает офлайн из `file://`)
- Процедурная графика монстров и героя, сгенерированные фоны биомов, синтезированный звук и музыка (WebAudio)
- Сохранение в `localStorage`, автосейв каждые 12 секунд и при выходе

## Структура репозитория

```
game/                     исходники игры (это и есть «www»)
  index.html
  css/style.css
  js/  util.js data.js state.js stats.js loot.js combat.js
       render.js audio.js minigames.js ui.js ui2.js main.js
  assets/                 фоны биомов, логотип
android/                  нативный Android-проект (WebView-оболочка)
  app/src/main/java/.../MainActivity.java
  app/src/main/assets/www/   <- сюда копируется game/ на этапе сборки
.github/workflows/build-apk.yml   CI: сборка APK через Gradle
```

## Готовый APK

`dist/Klinok-i-Monety-Kuznitsa-Khaosa.apk` — debug-сборка (~9 МБ), обновляется автоматически
на каждый пуш (GitHub Actions). Скачайте файл на телефон, разрешите установку из неизвестных
источников и установите. `minSdk = 24` (Android 7.0+), интернет не нужен.

## Сборка APK

APK собирается в GitHub Actions (нужен Android SDK + JDK, в песочнице они недоступны):

```bash
gh workflow run build-apk.yml --ref <branch>
gh run watch
gh run download -n blade-and-coins-apk
```

Локально (если есть Android SDK):

```bash
rm -rf android/app/src/main/assets/www && mkdir -p android/app/src/main/assets/www
cp -r game/. android/app/src/main/assets/www/
cd android && gradle assembleDebug
# APK: android/app/build/outputs/apk/debug/app-debug.apk
```

Debug-сборка подписана отладочным ключом — устанавливается на любое устройство
(разрешите «установку из неизвестных источников»).

## Играть в браузере

Откройте `game/index.html` или поднимите локальный сервер:

```bash
cd game && python3 -m http.server 8080
```
